# Software Configuration Management Using GitHub

## Project Overview
This project demonstrates a software configuration management
process using Git and GitHub.

## Objectives
- Source code version control
- Branch management
- Change control using Issues and Pull Requests
- Code review
- Continuous Integration with GitHub Actions
- Versioning and release management
- Configuration traceability

## Main Tools
- Git
- GitHub
- GitHub Projects
- GitHub Actions

## Project Duration
Approximately 5 weeks.
